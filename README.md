# InsuranceWala Premium Redesign

A premium modern redesign of the InsuranceWala website built using Lovable AI.

## Features
- Apple-inspired premium UI
- Responsive design
- Smooth animations
- Modern insurance landing page
- AI customer support chatbot
- Premium hero slider
- Glassmorphism effects
- Brand-focused redesign

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- Vite
- Lovable AI

## Live Preview
https://preview--insurancewala-premium-forge.lovable.app

## Project Purpose
This project was created to redesign and modernize the InsuranceWala brand experience with a clean, trustworthy, and premium aesthetic.
